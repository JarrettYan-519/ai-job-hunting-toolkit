# AI Job Hunting Toolkit 求职工具套装

> **当前版本：v1.1**（2026-06-15）｜[更新日志](#更新日志-changelog)

让 AI 陪你走完求职全流程——从投递到 Offer，每一步都有章法。

三个独立的 AI 提示词模板，覆盖求职的三个核心环节：**追踪进度** → **优化简历** → **备战面试**。

## 用法

1. 打开任意一个 `.md` 文件
2. 全文复制
3. 粘贴到 ChatGPT / Claude / Kimi / 豆包 / 通义千问 等任意 AI 聊天工具中
4. 开始对话

> 想封装成平台 Skill？见下方[平台封装指引](#平台封装指引)。

## 套装包含

| 工具 | 做什么 | 一句话 |
|------|--------|--------|
| [求职进度追踪](./job-tracker.md) | 投递记录 · 面试追踪 · 失败反馈分析 · 改进计划 | 你的求职 CRM |
| [简历分析与优化](./resume-optimizer.md) | JD 匹配分析 · 亮点挖掘 · 缺口识别 · 文案优化 | 你的简历顾问 |
| [面试准备与模拟](./interview-prep.md) | 八股问答 · 项目深挖 · 模拟面试 · 行为面试 | 你的模拟面试官 |

三个工具独立运行但自然联动——简历优化后的内容可以直接用于项目深挖练习，面试失败后的反馈可以自动生成改进计划。

### 功能分级

所有平台的 AI 都能完成**基础分析**（简历匹配、出题、复盘）。但**自动持久化**（把记录写进本地文件、跨会话读取历史）需要支持文件写入的平台：

| 能力 | 支持文件读写的平台（如 Claude Code、带工具调用的客户端） | 普通聊天窗口（ChatGPT/Kimi/豆包等） |
|------|-------------------------------------------------------|-------------------------------------|
| 基础分析（匹配/出题/复盘） | ✅ | ✅ |
| 自动写入本地文件 | ✅ | ❌（需手动复制保存） |
| 跨会话读取历史 | ✅ | ❌（需每次粘贴历史记录） |

普通聊天窗口用户：每次 AI 输出记录后，手动复制到对应的 `.md` 文件保存；下次新会话开始时把历史记录粘贴回去。

## 核心亮点

### 不只是记录，是分析

HR 说"项目经验不够"，求职进度追踪工具不会只记一句"挂了"。它会追问你被怼的是哪个项目、问的什么问题、你怎么回答的——然后给出具体到技术细节的分析和改进建议。

### 重复踩坑自动预警

同一个问题在不同面试里反复出现？工具会自动检测"重复模式"并高亮提醒——"这是你第三次因为系统设计答不好挂掉了，改进计划里的 IP-3 还没完成。"

### 面试前避坑清单

明天有 XX 公司面试？工具会调出该公司之前的失败反馈、同类岗位的高频挂点，生成一份 5 分钟看完的避坑清单。

## 适用人群

- 校招 / 实习求职的学生
- 社招跳槽的工程师（目前侧重技术岗位，AI/后端方向覆盖最全）
- 需要同时管理多条投递管线、容易忘记跟进的人
- 面试挂了但不知道为什么、想知道具体哪里需要补的人

## 使用建议

三个工具建议都配上，但它们之间不存在强依赖。最推荐的组合：

- **投递阶段**：用简历优化工具改好简历 → 投递 → 用求职进度追踪记录
- **面试阶段**：用面试准备工具模拟练习 → 面试 → 无论过没过都在求职进度追踪里记录
- **挂了之后**：把 HR/面试官反馈喂给求职进度追踪 → 拿到分析结果 → 改进计划里的知识点用面试准备工具补

## 平台封装指引

这些 `.md` 文件本质上是 AI 提示词。如果想在特定平台获得更好的体验，可以自行封装为 Skill/插件：

| 平台 | 封装方式 |
|------|---------|
| ChatGPT / Kimi / 豆包 等 | 直接复制粘贴到对话框，无需封装 |
| Proma | 复制到工作区 `skills/` 目录，关键词自动激活 |
| Claude Code | 复制到 `.claude/skills/<name>/SKILL.md`，通过 `/name` 调用 |
| Codex (OpenAI) | 复制到 `.agents/skills/<name>/SKILL.md`，自动发现或显式调用 |

封装不是必需的——直接复制粘贴到对话框就够用了。

## 更新日志 (Changelog)

### v1.1（2026-06-15）

基于两份提示词质量审查报告的系统性优化，覆盖三份提示词 + README：

**全局**
- 三份提示词各新增「通用规则」节：日期规则、反提示词注入、隐私脱敏、平台降级、提问节奏
- README 新增功能分级（基础分析 vs 自动持久化）和版本号

**job-tracker**
- 统一 ID 体系（`APP/INT/FB/IP` 带前缀），明确 ID 不得复用
- 新增状态机定义（`面试通过`/`被拒`/`已拒绝Offer`/`已主动放弃`），补接受 Offer 收尾规则
- 失败反馈改「索引表+详情块」，修复长文本损坏表格的 bug
- 补统计口径公式、会话恢复流程、判重粒度、删除/撤销操作、岗位方向字段

**resume-optimizer**
- 新增「事实边界」节，定义"具备"红线，禁止编造量化数据
- 评分锚点 + 加权 rubric，消除打分漂移
- 通用简历体检并入解析步骤
- 生成完整版前先输出确认层

**interview-prep**
- 首次分流协议（3 问题自动推荐模式）
- 三档时长 + 三档强度
- 联动闭环：读改进计划出题 + 模拟后写回
- AI Agent 题库 6 方向各补样题（few-shot）
- 岗位方向切换规则

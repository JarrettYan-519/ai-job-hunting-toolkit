# AI Job Hunting Toolkit 求职工具套装

让 AI 陪你走完求职全流程——从投递到 Offer，每一步都有章法。

三个独立的 AI 提示词模板，覆盖求职的三个核心环节：**追踪进度** → **优化简历** → **备战面试**。复制粘贴到 ChatGPT、Claude、Kimi 或任何 AI 工具中即可使用。

## 套装包含

| 工具 | 做什么 | 一句话 |
|------|--------|--------|
| [求职进度追踪](./universal/job-tracker.md) | 投递记录 · 面试追踪 · 失败反馈分析 · 改进计划 | 你的求职 CRM |
| [简历分析与优化](./universal/resume-optimizer.md) | JD 匹配分析 · 亮点挖掘 · 缺口识别 · 文案优化 | 你的简历顾问 |
| [面试准备与模拟](./universal/interview-prep.md) | 八股问答 · 项目深挖 · 模拟面试 · 行为面试 | 你的模拟面试官 |

三个工具独立运行但自然联动——简历优化后的内容可以直接用于项目深挖练习，面试失败后的反馈可以自动生成改进计划。

## 快速开始

### 方式一：通用版（任何 AI 工具）

1. 打开 `universal/` 目录下任意一个 `.md` 文件
2. 全文复制
3. 粘贴到 ChatGPT / Claude / Kimi / 豆包 / 通义千问 等任意 AI 聊天工具中
4. 开始对话

### 方式二：Proma 桌面应用

1. 将 `proma/` 目录下对应的文件夹复制到你的 Proma 工作区 `skills/` 目录
2. 在对话中提及求职相关关键词，Skill 会自动激活

## 核心亮点

### 不只是记录，是分析

HR 说"项目经验不够"，求职进度追踪工具不会只记一句"挂了"。它会追问你被怼的是哪个项目、问的什么问题、你怎么回答的——然后给出具体到技术细节的分析和改进建议。

### 重复踩坑自动预警

同一个问题在不同面试里反复出现？工具会自动检测"重复模式"并高亮提醒——"这是你第三次因为系统设计答不好挂掉了，改进计划里的 IP-3 还没完成。"

### 面试前避坑清单

明天有 XX 公司面试？工具会调出该公司之前的失败反馈、同类岗位的高频挂点，生成一份 5 分钟看完的避坑清单。

## 适用人群

- 校招 / 实习求职的学生
- 社招跳槽的工程师（目前侧重技术岗位，AI/后端方向覆盖最全）
- 需要同时管理多条投递管线、容易忘记跟进的人
- 面试挂了但不知道为什么、想知道具体哪里需要补的人

## 使用建议

三个工具建议都配上，但它们之间不存在强依赖。最推荐的组合：

- **投递阶段**：用简历优化工具改好简历 → 投递 → 用求职进度追踪记录
- **面试阶段**：用面试准备工具模拟练习 → 面试 → 无论过没过都在求职进度追踪里记录
- **挂了之后**：把 HR/面试官反馈喂给求职进度追踪 → 拿到分析结果 → 改进计划里的知识点用面试准备工具补
